## 🎓 Teaching Strategy

### Demo Flow Pattern
1. Show vulnerable code with clear vulnerability markers
2. Generate security tests with Copilot (show actual prompts)
3. Watch tests fail (proving vulnerability exists)
4. Apply fix using secure patterns
5. Watch tests pass (proving fix works)
6. Add to reusable test/prompt library

### Voice Characteristics
- **Opening hooks**: "Here's the thing about...", "Real talk:"
- **Teaching moments**: "The beauty of this approach...", "Think of this as..."
- **Transitions**: "Let's dive into...", "Now watch what happens..."
- **Emphasis**: "This is critical because...", "Don't skip this step..."

### Accessibility Conscious
- Never "as you can see" (they might not see)
- Never "obviously" (dismissive)
- Never "simply/just" (minimizes complexity)
