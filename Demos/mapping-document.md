# GitHub Copilot for Cybersecurity Specialists

## Master Repo–to–Module Mapping Document

**Author:** Tim Warner
**Purpose:** Internal tracking of vulnerable application repositories and how they map to course modules, demos, and Copilot-assisted workflows.

---

## Repositories Used in This Course

### **1. NodeGoat (Primary App – Node/Express)**

**URL:** [https://github.com/OWASP/NodeGoat](https://github.com/OWASP/NodeGoat)
**Role:** Anchor application for vulnerability detection, automated security testing, SAST/DAST, dependency scanning, and CI/CD security validation.
**Why:** Node-first. Lightweight. High signal-to-noise. Perfect for Copilot demos in web vulns and security automation.

---

### **2. WebGoat (Enterprise Auth + Threat Modeling)**

**URL:** [https://github.com/WebGoat/WebGoat](https://github.com/WebGoat/WebGoat)
**Role:** Enterprise-grade Java/Spring Boot vulnerability app used for authentication, authorization, encryption, threat modeling, and code-review modules.
**Why:** Provides realism. Richer architectural patterns. Great for Copilot-facilitated reasoning on controller flows and auth failures.

---

### **3. TerraGoat (IaC + Cloud Misconfiguration)**

**URL:** [https://github.com/bridgecrewio/terragoat](https://github.com/bridgecrewio/terragoat)
**Role:** Terraform-based cloud misconfiguration playground used for zero-trust, segmentation, compliance, CIS/NIST/STIG examples, and IaC scanning workflows.
**Why:** Terragoat gives you an entire cloud estate full of badly-configured infra that Copilot + GitHub Advanced Security can fix and document.

---

### **4. VulnerableApp (Optional Supplemental)**

**URL:** [https://github.com/SasanLabs/VulnerableApp](https://github.com/SasanLabs/VulnerableApp)
**Role:** Optional contrast application for demonstrating multi-language attacks and front-end flaws.
**Why:** Use only if needed for variety. NodeGoat + WebGoat + TerraGoat already cover ~95% of your demo needs.

# Module Mapping

---

## **Module 1: Vulnerability Detection with Copilot (40 min)**

**Primary Repo: NodeGoat**

### **1.1 Set Up Copilot + Secure Coding Practices**

* NodeGoat used for: enabling Copilot, secret scanning, code scanning setup.

### **1.2 SQL Injection Detection & Mitigation**

* NodeGoat SQLi routes demonstrate Copilot audit + refactoring.

### **1.3 XSS Detection & Prevention**

* NodeGoat templating flaws show input sanitization patterns.

### **1.4 Custom Copilot-Assisted Vulnerability Scanners**

* NodeGoat gives real endpoints for building CodeQL queries and scanners.

---

## **Module 2: Implement Security Protocols (40 min)**

**Primary Repos: WebGoat + TerraGoat**

### **2.1 Secure Authentication & Authorization Systems**

* WebGoat: broken auth, password handling, JWT misuse.

### **2.2 Encryption & Key Management**

* WebGoat crypto flows + Copilot-generated secure wrappers.

### **2.3 API Gateway Auth & Least Privilege Controls**

* WebGoat APIs + Copilot-generated gateway policies.

### **2.4 Zero-Trust Access + Segmentation (IaC)**

* TerraGoat: insecure IAM roles, SG/NSG misconfigurations.
* Copilot rewrites Terraform to enforce least privilege.

---

## **Module 3: Automated Security Testing (40 min)**

**Primary Repo: NodeGoat**
**Secondary: TerraGoat**

### **3.1 AI-Assisted Security Unit Tests**

* NodeGoat + Jest unit tests for high-risk routes generated by Copilot.

### **3.2 Fuzz Testing Harnesses**

* NodeGoat endpoints fuzzed via Copilot-generated Node scripts.

### **3.3 DAST & SAST Workflows**

* NodeGoat with CodeQL + ZAP Docker-based DAST pipelines.
* Copilot authors and explains the YAML.

### **3.4 Continuous Security Validation Pipelines**

* NodeGoat app checks + TerraGoat IaC scanning (Checkov, Trivy).
* CI integrates both app security and cloud misconfig validation.

---

## **Module 4: Security Code Review, Threat Modeling, Auditing (40 min)**

**Primary Repo: WebGoat**
**Supporting: NodeGoat**

### **4.1 Copilot-Assisted Secure Code Review & Threat Modeling**

* WebGoat controller flows analyzed with Copilot Chat.
* Visual threat modeling with Copilot-generated data flows.

### **4.2 Auto-Generated Checklists & Risk Reports**

* Copilot converts WebGoat diffs/PRs into review summaries.
* Generates actionable risk assessments.

### **4.3 Custom Security Linters & Static Analysis Rules**

* NodeGoat: ESLint/TS custom rules generated by Copilot.
* CodeQL rules written with Copilot for WebGoat or NodeGoat.

### **4.4 Dependency Vulnerability Assessment & Patching**

* NodeGoat: npm ecosystem + Dependabot + Copilot patch summaries.
* WebGoat: Maven dependencies and CVE review.

---

## **Module 5: Compliance, Incident Response, Configuration Mgmt (40 min)**

**Primary Repo: TerraGoat**
**Supporting: NodeGoat (for documentation examples)**

### **5.1 Compliant IaC Templates & Baselines**

* TerraGoat: Copilot rewrites Terraform modules to CIS-aligned patterns.

### **5.2 Automate CIS & NIST Benchmark Verification**

* Copilot generates Checkov/OPA policies for TerraGoat’s IaC.
* GitHub Actions used to enforce compliance gates.

### **5.3 STIG Validation & Auto-Remediation**

* TerraGoat misconfigs auto-fixed with Copilot proposals.
* Add STIG-like controls for cloud infra.

### **5.4 Automation of Security Docs, Audit Logs, IR Playbooks**

* Copilot creates IR playbooks, audit summaries, and Markdown security reports using alerts from NodeGoat + TerraGoat.

---

**TerraGoat** = IaC security, zero-trust, segmentation, compliance, cloud remediation
**VulnerableApp** = Optional flavor injector for front-end or alt-stack examples
